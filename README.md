## 📌 Project Overview

This project was developed as part of the TripleTen Data Science program and focuses on applying fundamental Python programming concepts to a fictional e-commerce company called **Store 1**.

The company collects customer information and purchasing data to better understand customer behavior and support business decisions.

Through a series of practical exercises, the project demonstrates how Python can be used to clean customer records, standardize information, calculate spending, and identify customer segments.

## 🎯 Project Objectives

- Identify and correct inconsistencies in customer data.
- Convert and validate data types.
- Clean and standardize customer names.
- Work with lists and strings.
- Apply error handling techniques.
- Calculate customer spending and company revenue.
- Use loops and conditional statements.
- Filter customers based on age, spending, and product preferences.

## 🔍 Project Tasks

### 1. Data Quality and Standardization

The project begins by examining customer information and identifying potential inconsistencies.

The exercises include:

- Removing unnecessary whitespace from customer names.
- Replacing underscores with spaces.
- Converting customer ages to integer values.
- Standardizing product categories to lowercase.

### 2. Error Handling

The project uses `try` and `except` to handle invalid age values without immediately terminating program execution.

This introduces an important concept for developing more reliable data-processing workflows.

### 3. Customer Spending Analysis

Customer spending is analyzed using built-in Python functions.

The exercises calculate:

- Total spending across product categories.
- Maximum spending in a category.
- Minimum spending in a category.

### 4. Loyalty Discount Simulation

A `while` loop simulates additional purchases until a customer reaches a spending threshold of **$1,500**.

This exercise demonstrates iteration, conditional logic, and random number generation.

### 5. Customer Information Formatting

Python f-strings are used to create readable summaries containing customer identifiers, names, and ages.

### 6. Revenue Calculation

The project processes customer records stored in nested lists and calculates total company revenue by aggregating purchase amounts.

### 7. Customer Segmentation

Conditional statements and loops are used to identify:

- Customers younger than 30.
- Customers younger than 30 who spent more than $1,000.
- Customers who purchased clothing.

These exercises introduce basic customer segmentation concepts.
